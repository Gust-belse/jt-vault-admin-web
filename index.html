Kiến trúc bảo mật 4 tầng (Frontend + PostgreSQL Cloud)

Toàn bộ quy tắc phân quyền và mã hóa được cưỡng chế trực tiếp tại PostgreSQL & Edge Function, không phụ thuộc giao diện.

Tầng 01 · Tài khoản

Tắt đăng ký công khai

Chỉ Admin AAL2 được cấp tài khoản qua Edge Function admin-create-user. Ép đổi mật khẩu mạnh ≥ 12 ký tự ngay lần đầu.

Tầng 02 · Xác thực

Bắt buộc MFA (AAL2)

Mọi hàm RPC quản trị kiểm tra auth.jwt() ->> 'aal' = 'aal2'. Tài khoản HQ/Regional hoặc chưa xác thực OTP bị chặn 42501.

Tầng 03 · Bí mật

Supabase Vault Write-Only

Token JMS, Feishu OAuth và mật khẩu JMS mã hóa trong vault.secrets. Trình duyệt chỉ nhận chuỗi che, không bao giờ nhận plaintext.

Tầng 04 · Truy vết

Nhật ký bất biến

Bảng security_audit_logs gắn trigger chặn tuyệt đối UPDATE/DELETE, ghi vết đầy đủ thao tác không chứa bí mật gốc.

Triển khai dữ liệu lên Supabase Cloud trong 4 bước

Tất cả SQL Schema, RLS, Supabase Vault RPC và Edge Function đã được đóng gói sẵn trong repository này.

Bước 1 · Khởi tạo Cloud Database

Chạy SQL Migration trên Supabase Cloud

Tạo project miễn phí tại supabase.com, mở SQL Editor và chạy tệp 01-supabase-db/full_deploy_supabase_sql_editor.sql (hoặc đẩy bằng Supabase CLI).

bash 04-cloud-deploy/deploy-supabase.sh <PROJECT_REF>
Bước 2 · Cấp Super Admin đầu tiên

Tạo tài khoản Auth & chạy hàm Bootstrap

Trong Authentication → Providers → Email hãy tắt Allow new users to sign up, tạo user Admin trong mục Users, sau đó chạy lệnh sau tại SQL Editor:

01-supabase-db/004_bootstrap_first_admin.sql 
SELECT private.bootstrap_first_admin(
  'admin@jtexpress.vn', 'Quản Trị Viên Hệ Thống', false
);
Bước 3 · Kết nối Website GitHub Pages

Điền Public URL & Public Anon Key

Vào Project Settings → API để lấy Project URL và anon public key, điền vào 02-vault-admin-ui/js/config.js hoặc nhập trực tiếp trên màn hình kết nối nhanh của Kho Bảo Mật.

export const SUPABASE_CONFIG = Object.freeze({
  url: 'https://YOUR_PROJECT_REF.supabase.co',
  anonKey: 'YOUR_SUPABASE_ANON_KEY'
});
Bước 4 · Kiểm thử Sandbox tự động

Xác minh bảo mật 4 tầng bằng Docker + Python

Chạy bộ kiểm thử tích hợp trong 05-sandbox-pipeline/ để kiểm tra RLS, chặn 42501, mã hóa Vault và tính bất biến của Audit Log trước khi đưa vào vận hành:

05-sandbox-pipeline 
docker compose -f 05-sandbox-pipeline/docker-compose.test.yml up -d
python3 05-sandbox-pipeline/run_executor_and_integration.py --stage all
